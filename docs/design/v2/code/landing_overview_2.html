Limites d'utilisation • Scientific Caveats

info Detection tool, not a forecast • Outil de détection, non prédictif
update

1. Temporal Cadence

One pass every 12 days: short flash floods can be missed.

Un survol tous les 12 jours : les crues éclairs de courte durée peuvent échapper à la détection.

wb_twilight

2. Urban Double-Bounce

Flooded streets look brighter, not darker: that layer is less certain.

Les rues inondées apparaissent plus claires et non sombres : cette couche comporte une incertitude accrue.

waves

3. Maritime Masking

Tide and waves near the Wouri estuary are masked out.

Les marées et la houle côtière aux abords du fleuve Wouri sont masquées pour éviter les faux positifs.
